# Эмулятор обмена с 1С

Модуль для **1С-Битрикс**, эмулирующий полноценные живые сессии обмена с 1С:Enterprise поверх штатного `/bitrix/admin/1c_exchange.php`. Вместо реальной 1С администратор запускает тот же протокол из админки и видит пошаговый лог сессии, прогресс и статистику.

## Возможности

- **Импорт каталога** — полная сессия живого протокола: `checkauth → init → file×N → import×N → deactivate → complete`; файл передаётся в ядро частями, как это делает 1С
- **Экспорт заказов** — этап B1 живого обмена: `checkauth → init (2.09) → query×N → success`, результат — собранный CommerceML-файл «что получила бы 1С»
- **Консоль протокола** — лента шагов сессии, статус-бейджи каждой строки (SUCCESS / PROCESS / WARNING / STOP / ERROR), время и длительность шагов, прогресс с ETA
- **Статистика** — одна страница: KPI-сводка, последние импорты, статистика по файлам
- Логирование шагов в БД
- Эмуляция соблюдает штатные [настройки обмена](/bitrix/admin/1c_admin.php) (интервал шага, zip, кэш инфоблока, действия с отсутствующими элементами/разделами)

## Требования

- PHP 8.0+
- 1С-Битрикс (редакции с модулем «Торговый каталог» и интернет-магазином — для экспорта заказов)
- MySQL / MariaDB

## Установка

1. Скопировать модуль в `bitrix/modules/ps.emulator1c/` (или `local/modules/ps.emulator1c/`)
2. Установить модуль: админка → Marketplace → Установленные решения → «Эмулятор обмена с 1С»
3. Раздел в админке: **Сервисы → Эмуляция обмена с 1С** (импорт каталога, заказы в 1С, статистика)

## Архитектура

```
install/           — инсталлятор (CModule), SQL-схема, CSS/JS-ассеты
lib/               — PHP-классы в namespace Ps\Emulator1c
  Logger.php       — запись шагов сессии в ps_emulator1c_log
  Stats.php        — агрегированная статистика импортов
admin/             — страницы админки (импорт, заказы, статистика)
include.php        — регистрация автозагрузки D7
```

**БД:** одна таблица `ps_emulator1c_log` (ID, DATE_CREATE, FILE_NAME, STATUS, MESSAGE). STATUS: SUCCESS, PROCESS, WARNING, STOP, ERROR.
