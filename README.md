# Эмулятор выгрузки 1С

Модуль для **1С-Битрикс**, позволяющий эмулировать стандартный процесс импорта каталога из 1С:Enterprise. Вместо реального HTTP-обмена с 1С администратор загружает XML-файл вручную через панель управления и запускает встроенный конвейер импорта Битрикса в пошаговом режиме с отслеживанием прогресса.

## Возможности

- Загрузка XML-файлов выгрузки 1С через веб-интерфейс
- Пошаговый запуск стандартного скрипта `1c_exchange.php` с визуальным прогресс-баром
- Таймер выполнения с оценкой оставшегося времени
- Логирование каждого шага импорта в базу данных
- Страница статистики: общая статистика, история импортов, статистика по файлам
- Возможность обнуления шага и остановки импорта
- Настройки модуля: пропуск проверки источника, режим безопасного обмена

## Требования

- PHP 8.0+
- 1С-Битрикс (любая редакция с модулем «Торговый каталог»)
- MySQL / MariaDB

## Установка

1. Скопируйте директорию `ps.emulator1c` в `bitrix/modules/`
2. Перейдите в панель управления Битрикс: **Настройки → Модули**
3. Найдите модуль «Эмулятор выгрузки 1С» и нажмите «Установить»

При установке автоматически:
- создаётся таблица `ps_emulator1c_log` для логирования
- административные скрипты копируются в `bitrix/admin/`
- JS и CSS ассеты копируются в `bitrix/js/ps.emulator1c/` и `bitrix/css/ps.emulator1c/`

## Использование

### Импорт файлов

1. В левом меню Битрикс откройте **Контент → Эмуляция 1С выгрузки → Импорт файлов**
2. Выберите XML-файл выгрузки 1С и нажмите «Загрузить»
3. Наблюдайте за ходом импорта: прогресс-бар, лог шагов, таймер
4. При необходимости можно обнулить шаг импорта или остановить процесс

### Просмотр статистики

**Контент → Эмуляция 1С выгрузки → Статистика**

- **Общая статистика** — количество успешных импортов, среднее время выполнения
- **Последние импорты** — журнал последних операций с датами и статусами
- **Статистика по файлам** — сводка по каждому загруженному файлу (количество шагов, успешных импортов, ошибок, длительность)

### Настройки модуля

**Настройки → Настройки продукта → Настройки модулей → Эмулятор выгрузки 1С**

- **Пропускать проверку источника** — отключает проверку источника запроса при импорте (аналог `DEFAULT_SKIP_SOURCE_CHECK`)
- **Безопасный обмен с 1С** — включает/выключает безопасный режим обмена (аналог `secure_1c_exchange`)

## База данных

Модуль использует одну таблицу — `ps_emulator1c_log`:

| Поле         | Тип           | Описание                           |
|--------------|---------------|------------------------------------|
| ID           | int, AI       | Первичный ключ                     |
| DATE_CREATE  | datetime      | Дата и время записи                |
| FILE_NAME    | varchar(255)  | Имя импортируемого файла           |
| STATUS       | varchar(50)   | Статус: START, PROCESS, SUCCESS, ERROR, STOP |
| MESSAGE      | text          | Текстовое описание шага            |

## Как это работает

1. **Загрузка** — файл копируется в `/upload/1c_catalog/`, сбрасывается шаг импорта в сессии
2. **Импорт** — JS-клиент `PsEmulator1C` в цикле отправляет XHR-запросы к `/bitrix/admin/1c_exchange.php?type=catalog&mode=import&filename=...`
3. **Разбор ответа** — скрипт различает ответы `progress` (продолжить) и `success` (завершено), а также ошибки
4. **Логирование** — каждый шаг логируется через AJAX-запрос к PHP-бэкенду, который записывает в `ps_emulator1c_log`
5. **Статистика** — агрегируется из таблицы логов: количество импортов, среднее время, сводка по файлам
